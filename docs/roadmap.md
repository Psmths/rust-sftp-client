# Roadmap

- [ ] **Foundation:** workspace, Tauri shell, frontend scaffold, CI, formatting and linting.
- [ ] **SSH security:** host-key verification, password authentication, private keys, passphrases, SSH agent.
- [ ] **SFTP filesystem:** list, stat, mkdir, rename, delete, permissions, safe path handling.
- [ ] **File manager:** dual-pane UI, navigation, selection, context menus, drag and drop.
- [ ] **Transfers:** queue, progress, pause/cancel, single-stream upload/download.
- [ ] **Segmented downloads:** offset-based range planner, bounded workers, positional writes, retries.
- [ ] **Resume:** durable state, remote revalidation, restart/recovery behavior.
- [ ] **Performance:** connection reuse, bounded buffers, keepalive/socket options where supported, benchmarks.
- [ ] **Release:** platform packaging, integration tests, security review, user documentation.
